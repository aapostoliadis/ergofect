Running the website locally
Prerequisites
Node.js 18 or later

npm

Setup
git clone <repository-url>
cd <repository-folder>
npm install
npm run dev
Open the local address shown in the terminal.

Available scripts
npm run dev      # Start the local development server
npm run build    # Create a production build
npm run preview  # Preview the production build locally
Script names may vary by framework. Check package.json for the current commands.

Deployment
The website is deployed through Vercel. Commits pushed to the connected production branch trigger a new deployment.

Store configuration values in Vercel Environment Variables. Do not commit API keys, access tokens, or passwords to this repository.

Contributing
This is a privately maintained business website. If you are working on the project:

Create a branch from the latest production branch.

Make and test your changes locally.

Open a pull request with a clear description and screenshots for visual changes.

Confirm the Vercel preview before merging.
